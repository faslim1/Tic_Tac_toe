# Tic_Tac_toe
TIC-TAC-TOE GAME 👾
=================

Description:
This is a simple two-player Tic-Tac-Toe game created using Python.
Player 1 uses X and Player 2 uses O.

Requirements:
- Python 3.x
- No additional libraries are required.

How to Run:
1. Download or save the Python file as tic_tac_toe.py.
2. Open a terminal or command prompt.
3. Navigate to the folder containing the file.
4. Run the following command:

   python tic_tac_toe.py

How to Play:
- The board contains positions numbered from 1 to 9.
- Players take turns entering a position.
- The first player to get three marks in a row, column, or diagonal wins.
- If all positions are filled without a winner, the game ends in a draw.
- After the game ends, players can choose whether to play again.
